## 🚀 Sobre este Portfolio

Portfolio web personal desarrollado con HTML5, CSS3, JavaScript y Bootstrap. Presenta mi trayectoria profesional como docente y desarrollador, proyectos destacados, formación académica y certificaciones profesionales.

### ✨ Características

- ✅ Diseño responsive y moderno
- ✅ Animaciones fluidas con Typed.js y AOS
- ✅ Secciones interactivas (Proyectos, Formación, Contacto)
- ✅ Integración con redes sociales
- ✅ Carrusel de certificaciones con Owl Carousel
- ✅ Lightbox para visualización de imágenes
- ✅ Optimizado para SEO

## 🚀 Instalación y Uso

### Clonar el repositorio
```bash
git clone https://github.com/rusgar/portfolio.git
cd portfolio
```

### Abrir en navegador
```bash
# Opción 1: Doble click en index.html

# Opción 2: Servidor local con Python
python -m http.server 8000

# Opción 3: Live Server (VS Code)
# Instala la extensión Live Server y click derecho > Open with Live Server
```

### Personalización
1. Edita `index.html` para actualizar contenido
2. Modifica `css/styles.css` para cambiar estilos
3. Actualiza imágenes en la carpeta `img/`
4. Configura enlaces de redes sociales
